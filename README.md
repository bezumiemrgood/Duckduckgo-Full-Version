## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Web Tracking Protection** — Blocks tracking systems before they load, minimizing bandwidth usage.
- **Cookie Warning Blocker** — Automatically dismisses cookie consent pop-ups for a cleaner browsing experience.
- **DuckDuckGo Integration** — Set DuckDuckGo as your default search engine for private searches.
- **Fire Button** — Quickly erase private data like passwords, history, and bookmarks with a single click.
- **Intelligent Encryption** — Automatically applies HTTPS wherever possible, enhancing your security.

### Advanced Features:
- **Email Protection** — Safeguards your email communications from prying eyes.
- **Privacy Log** — Provides real-time tracking of identified trackers, allowing users to stay informed about their privacy status.
